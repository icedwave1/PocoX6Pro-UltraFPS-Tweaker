# Poco X6 Pro 5G (duchamp) — Ultra FPS Tweaker with KernelSU WebUI

Экстремальный твикер производительности и устранения фризов, созданный специально для **Poco X6 Pro 5G** (`duchamp` / MediaTek Dimensity 8300-Ultra) под управлением прошивки **Pixel Experience / AOSP** с рутом **KernelSU** (также совместим с APatch и Magisk).

---

## 🔥 Ключевые возможности

### 1. Архитектурные твики MediaTek Dimensity 8300-Ultra & Mali-G615
* **CPU Scheduler & UCLAMP**:
  - Принудительное выделение 100% мощности CPU для активной игры (`top-app uclamp.min = 100%`, `latency_sensitive = 1`).
  - Минимизация задержек миграции потоков между кластерами (4x Cortex-A510 + 3x Cortex-A715 + 1x Cortex-A715 Prime).
* **MediaTek GED & FPSGO (Mali GPU DVFS)**:
  - Форсирование игрового режима драйвера GPU (`gx_game_mode = 1`, `gx_force_cpu_boost = 1`).
  - Агрессивный DVFS margin — видеочип не сбрасывает частоты в тяжёлых сценах.
* **Thermal Throttling Bypass**:
  - Отключение агрессивного троттлинга температурных зон, предотвращающее просадку FPS при длительных сессиях.
* **120Hz Force Lock (Pixel Experience)**:
  - Блокировка сброса герцовки до 60Hz при отсутствии касаний и в неоптимизированных играх.
* **Устранение микрофризов (Anti-Stutter)**:
  - Отключение фонового ядра трейсинга `ftrace` и ограничение буфера логов `logd`.
  - Оптимизация очередей UFS 4.0 хранилища для мгновенной подгрузки игровых ассетов и текстур.
  - Настройка параметров сброса `dirty_ratio` для предотвращения I/O зависаний.

## 💻 Полнофункциональный WebUI в KernelSU

Модуль включает встроенный веб-интерфейс в стиле Cyberpunk / Dark OLED, доступный прямо из приложения **KernelSU Manager**:

1. **Главный переключатель**: Включение / Выключение одним тапом.
2. **Профили в 1 клик**:
   - 🚀 **EXTREME**: Полный разгон, обход троттлинга, 120Hz lock, максимальный FPS.
   - ⚡ **BALANCED**: Высокая производительность с контролем нагрева.
   - 🔋 **BATTERY**: Энергосбережение для повседневного использования.
   - 🔄 **STOCK**: Полный откат к заводским настройкам Pixel Experience.
3. **Живая телеметрия (Live Telemetry)**:
   - Температура CPU (AP) и аккумулятора.
   - Частоты всех трех кластеров ядер в реальном времени.
   - Текущая частота обновления экрана и активный говернор.
4. **Быстрые действия (Quick Actions)**:
   - 🎯 **Boost текущей игры (PID Realtime)**: находит игру на экране, выставляет приоритет `nice -20`, `ionice realtime`, защиту от выгрузки `oom_score_adj -900` и закрепляет за производительными ядрами.
   - 🧹 **Очистить RAM и кэш**: сброс кэшей (`drop_caches`) и компактизация памяти без перезагрузки.
   - 📋 **Консоль логов**: вывод команд в реальном времени.

## 📦 Установка

Готовый архив для прошивки:
`PocoX6Pro-UltraFPS-Tweaker.zip`

### Способ 1: Через приложение KernelSU Manager (на телефоне)
1. Скопируйте файл `PocoX6Pro-UltraFPS-Tweaker.zip` в память телефона.
2. Откройте приложение **KernelSU**.
3. Перейдите во вкладку **«Модули»** -> нажмите **«Установить»**.
4. Выберите архив `PocoX6Pro-UltraFPS-Tweaker.zip`.
5. После установки откройте WebUI прямо из списка модулей!

### Способ 2: Через ADB (с компьютера)
```bash
adb push PocoX6Pro-UltraFPS-Tweaker.zip /sdcard/
# Установка через ksud (если установлен):
adb shell su -c "ksud module install /sdcard/PocoX6Pro-UltraFPS-Tweaker.zip"
```

- Тап по ней мгновенно переключает режим между **EXTREME GAMING** и **STOCK**.
